# Web Dashboard

Next.js dashboard for Nami.

Current Phase 3 scope:

- Next.js App Router with TypeScript.
- Tailwind CSS theme tokens.
- shadcn-style local UI primitives.
- V1 pages: Home, Chat, Tasks, Projects, Automations, Approvals, Logs, Settings.
- Chat page connected to the local Nami API at `NEXT_PUBLIC_API_URL`.
- Approvals page connected to the approval API.
- Logs page connected to the action-log API.

Voice, memory, n8n, email/calendar, browser automation, screen control, and
document generation logic are not implemented here yet.
