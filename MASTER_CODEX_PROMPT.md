## Mission

Build Nami, a personal JARVIS-like AI assistant for Kaif, that can eventually:

- Chat and talk by voice
- Wake using "Hey Nami"
- Understand typed/spoken commands
- Remember profile, projects, jobs, clients, tasks, and preferences
- Research the web and summarize sources
- Check weather/time/current information
- Trigger n8n workflows
- Write emails and create drafts
- Schedule meetings
- Customize resumes and cover letters
- Help apply for jobs with approval
- Manage clients/projects
- Create documents/reports/PDF/PPT/Excel
- Use browser automation
- Watch screen and guide the user
- Later click/type/control apps safely
- Coordinate Codex for software building
- Protect secrets and ask approval for risky actions
