# 38 — Resume and Job Assistant

## Goal

Help Kaif apply for jobs professionally.

## Features

- Master resume profile
- Job description analyzer
- ATS keyword extraction
- Resume customization
- Cover letter generation
- HR email/WhatsApp message drafting
- Job application tracker
- Interview preparation
- Follow-up reminders

## Job application workflow

```text
User gives job link/JD
→ Nami analyzes JD
→ Matches Kaif profile
→ Customizes resume
→ Creates cover letter
→ Fills form if requested
→ Stops before submit
→ Asks approval
→ Logs application
```

## Rule

Do not invent fake experience. Use real projects, skills, and fresher-friendly positioning.
