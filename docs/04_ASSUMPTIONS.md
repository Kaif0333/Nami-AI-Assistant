# 04 — Assumptions

## User assumptions

- Kaif has limited coding knowledge.
- Kaif will use VS Code and Codex 5.5 as the main builder.
- Kaif can create API accounts and provide credentials locally.
- Kaif can test features and paste errors back if needed.
- Kaif wants a polished final product, not just a demo.

## Technical assumptions

- Development is on Windows.
- GitHub repo exists: Kaif0333/Nami-AI-Assistant.
- Node.js, Git, VS Code, Docker, and Codex extension can be installed.
- External APIs may require paid usage.
- Some features require OAuth/account setup.
- Full computer control is later phase and should be built carefully.

## Product assumptions

- n8n handles automation only.
- Nami custom app handles brain, memory, dashboard, voice, screen, and approvals.
- Codex builds code but does not make product decisions randomly.
