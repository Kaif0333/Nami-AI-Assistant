# 35 — Screen and Computer Control

## Goal

Nami should observe screen, explain what is happening, and later control apps safely.

## Modes

### Observe Mode
Nami sees screen and explains.

### Guide Mode
Nami tells user what to click/type.

### Control Mode
Nami clicks/types with approval.

## Capabilities

- Read visible screen
- Understand terminal errors
- Understand VS Code
- Understand browser forms
- Watch video flow
- Guide user live
- Later use mouse/keyboard

## Safety

- Show "Nami is watching screen."
- Emergency stop.
- No secret monitoring.
- Approval before control.
- Sensitive-page blocker.

## Reliability order

Use:
1. Official APIs
2. Playwright
3. Accessibility/UI automation
4. Vision + mouse/keyboard
