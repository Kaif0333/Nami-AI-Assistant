# 71 — QA Strategy

## QA principle

Nami should fail safely and clearly.

## QA levels

### Developer QA
Codex runs tests after changes.

### Manual QA
Kaif tests features with checklist.

### Regression QA
Previously working features must remain working.

### Security QA
Approval gates and secrets must be checked.

## Done means done

A phase is not done until:
- Feature works
- Tests/checks pass
- Documentation updated
- Errors handled
- Logs added
