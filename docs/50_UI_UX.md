# 50 — UI/UX

## Design goal

Nami should look like a premium AI command center.

## Style

- Pure white background
- Off-white surfaces
- Citrus orange primary actions and highlights
- Soft citrus accent states
- Ink black text and borders
- Animated voice orb
- Clean fonts
- Calm premium command-center feel
- Not overdone
- Not childish

## UX rule

User should always know:
- What Nami is doing
- What Nami needs
- What is pending approval
- What failed
