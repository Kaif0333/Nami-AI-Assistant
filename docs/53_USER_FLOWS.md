# 53 — User Flows

## Research flow

User asks research query → Nami searches → summarizes → shows sources → saves report if approved.

## Email flow

User asks reply → Nami drafts → approval card → send after approval → log.

## Resume flow

User gives JD → Nami analyzes → creates tailored resume/cover letter → saves version → prepares application.

## Job apply flow

User asks apply → Nami fills form → stops before submit → asks approval → submits if approved → logs.

## n8n flow

User asks automation → Nami triggers webhook → n8n runs → callback/log → Nami reports.

## Screen flow

User enables screen → Nami observes → explains/guides → control only after approval.

## Codex build flow

User gives idea → Nami creates docs/tasks → Codex builds → tests → Nami helps review.
