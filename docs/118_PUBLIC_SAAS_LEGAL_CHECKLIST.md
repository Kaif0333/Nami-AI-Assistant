# 118 — Public SaaS Legal Checklist

## Purpose

Nami starts as a personal local assistant. This document applies only if Kaif later turns Nami into a public SaaS.

## Not required for Phase 0 or V1

Do not delay local Nami because of SaaS legal work.

## Required before public SaaS launch

- Privacy Policy
- Terms of Service
- Refund policy if paid
- Cookie policy if web app uses cookies
- Data deletion/export process
- User account deletion process
- Billing terms
- Abuse policy
- Security contact
- Data retention policy

## Technical SaaS requirements

- Authentication
- User/workspace separation
- Tenant isolation
- Role-based access
- Usage limits
- Billing integration
- Audit logs
- Admin dashboard
- Backups
- Monitoring

## Codex rule

Do not build SaaS complexity into V1. Keep the data model future-compatible with user/workspace IDs where reasonable.
