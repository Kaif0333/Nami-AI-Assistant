# 41 — Client Project Manager

## Goal

Help Kaif manage client projects.

## Features

- Client profile
- Project requirements
- Proposal drafts
- Pricing notes
- Meeting summaries
- Follow-up reminders
- Deadline tracker
- Deliverable tracker
- Invoice/proposal reminders

## Workflow

```text
Client request
→ Nami summarizes requirements
→ Creates project plan
→ Creates proposal
→ Tracks tasks
→ Drafts follow-up
→ Asks approval before sending
```
