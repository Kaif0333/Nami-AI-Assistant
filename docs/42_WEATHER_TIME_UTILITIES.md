# 42 — Weather and Time Utilities

## Goal

Nami can answer live utility queries.

## Weather

Nami should:
- Ask/use location
- Fetch current/upcoming forecast
- Summarize clearly
- Avoid guessing

Example:
"Nami, check weather in Hyderabad."

## Time

Nami should:
- Use timezone library/API
- Answer current time by city
- Convert meeting times

Example:
"Nami, what time is it in New York?"

## Rule

For current info, use a tool/API, not memory.
