# 02 — Final Scope

## In scope

Nami final product should include:

1. Desktop/dashboard app
2. Chat assistant
3. Voice interaction
4. Wake word later
5. Personal memory
6. Web/deep research
7. Weather/time utilities
8. n8n automation bridge
9. Email assistant
10. Calendar assistant
11. Resume customizer
12. Job application assistant
13. Client/project manager
14. Document generator
15. Browser automation
16. Screen observe/guide mode
17. Safe computer control prototype
18. Codex builder module
19. Approval system
20. Logs/audit system
21. Settings and credentials manager
22. Testing framework
23. Packaging/deployment docs

## V1 scope

- Dashboard
- Chat
- Settings
- Logs
- Approvals
- Tasks/projects placeholders
- Basic AI response
- Basic memory placeholder
- n8n webhook test

## Final product scope

Everything in the in-scope list, built phase by phase.

## Must-have quality

- No secrets in GitHub
- Approval gates for risky actions
- Errors visible and recoverable
- Logs for actions
- Tests for critical logic
