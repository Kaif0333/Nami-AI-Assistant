# 00 — Product Bible

## Product name

Nami AI Assistant

## Product category

Personal AI operating system / JARVIS-like AI assistant.

## Product mission

Nami helps Kaif convert natural language into useful work: research, planning, coding, automation, documents, job applications, emails, meetings, and system workflows.

## Core principle

Nami is not a chatbot. Nami is an action-capable assistant with memory, tools, approvals, logs, and modular agents.

## Main product promise

Nami should help Kaif work faster, learn faster, build software faster, apply for jobs better, manage clients better, and automate repeated tasks safely.

## What makes Nami special

- Personal memory
- Voice-first workflow
- Screen awareness
- n8n automation bridge
- Codex builder coordination
- Job/resume assistant
- Client/project workflow support
- Approval system
- Premium dashboard

## Target quality

Nami should feel like a serious product:

- Clean UI
- Safe actions
- Clear logs
- Recoverable errors
- Strong documentation
- Modular architecture
- Phase-based build
