# 37 — Email and Calendar

## Email capabilities

- Search email
- Summarize email
- Draft replies
- Label emails
- Track important messages
- Auto-reply low-risk emails if configured
- Ask approval before sending

## Calendar capabilities

- Check availability
- Schedule meeting
- Add attendees
- Add Google Meet later
- Reschedule/cancel with approval
- Create agenda

## Rules

- Drafting is allowed.
- Sending requires approval.
- Sensitive communication requires approval.
- Meeting invites require approval.
- No impersonation.
