# 05 — Constraints

## Development constraints

- User has limited coding knowledge.
- Codex should handle most coding.
- Work must be phase-based.
- Windows setup may create tooling issues.
- API keys must stay local.

## Technical constraints

- Live voice can have latency.
- Screen control can misclick.
- Browser automation can break if websites change.
- CAPTCHA cannot be bypassed.
- Some desktop apps may not expose accessibility data.
- AI models can hallucinate.
- Costs can increase with voice/vision/research usage.

## Safety constraints

- Risky actions require approval.
- Sensitive data must be protected.
- Logs must not expose full secrets.
- Hidden monitoring is not allowed.
