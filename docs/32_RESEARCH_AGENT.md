# 32 — Research Agent

## Goal

Nami can do fast and deep internet research.

## Capabilities

- Search web
- Read webpages
- Summarize
- Compare tools
- Research companies
- Research coding libraries
- Research current information
- Provide citations/links
- Create action plan

## Modes

### Fast mode
For quick answers like:
- time
- weather
- current version
- one source summary

### Deep mode
For:
- tech stack research
- competitor comparison
- company research
- project planning
- feasibility analysis

## Output

- Summary
- Key findings
- Recommendations
- Risks
- Action plan
- Sources

## Rule

For current information, Nami must check sources. It must not guess.
