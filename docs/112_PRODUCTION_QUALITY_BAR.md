# 112 — Production Quality Bar

## Purpose

Define what "perfect" means for Nami.

Perfect does not mean no bugs ever. Perfect means professional product standards.

## Product quality

- Clear purpose
- Consistent UI
- Fast enough
- Useful daily
- Safe by default
- Modular
- Documented
- Testable

## Engineering quality

- Strong types
- Clean folder structure
- Clear APIs
- Tests
- Error handling
- Logs
- No secrets
- Good commits
- Updated docs

## AI quality

- Agents have clear roles
- Prompts are tested
- Security agent blocks risky actions
- Verifier checks outputs
- Memory is controlled
- Research uses sources
- Actions ask approval

## Automation quality

- n8n workflows have clear triggers
- Webhooks are secured
- Failures are logged
- Retries are safe
- Risky sends/submits require approval

## UI quality

- Premium citrus command-center theme
- Canonical palette applied consistently: Citrus Orange, Soft Citrus, Pure White, Off-White, and Ink Black
- Clean layout
- Clear status
- Approval cards
- Error states
- Loading states
- Empty states
- Accessible controls

## Final product quality

Nami is final-product-ready only when:

- All final acceptance criteria pass
- No critical security issues
- No secret leakage
- Core workflows stable
- Documentation complete
- Setup reproducible
- User can recover from errors
