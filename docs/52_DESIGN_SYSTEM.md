# 52 — Design System

## Theme

Premium citrus command-center professional.

## Colors

Canonical frontend palette:

| Role | Color Name | Hex Code |
|---|---|---|
| Primary | Citrus Orange | `#F97316` |
| Light Accent | Soft Citrus | `#FFEDD5` |
| Background | Pure White | `#FFFFFF` |
| Surface | Off-White | `#F9FAFB` |
| Text/Borders | Ink Black | `#111827` |

Supporting states:
- Success: use a restrained green that remains readable on Pure White and Off-White.
- Warning: use a warm amber that harmonizes with Citrus Orange.
- Danger: use a strong red/orange-red with accessible contrast.
- Disabled/muted: use Soft Citrus or low-opacity Ink Black.

## Components

- Sidebar
- Top bar

## Interaction

- Smooth transitions
- Clear hover states
- No excessive animation
- Keyboard accessible
