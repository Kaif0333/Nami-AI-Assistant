# 08 — Product Requirements Document

## Overview

Nami AI Assistant is a personal AI assistant and command center for Kaif. It combines AI chat, voice, memory, research, n8n automation, jobs/resumes, client/project workflows, document generation, and future screen/computer control.

## Goals

- Help Kaif complete daily digital work faster.
- Support job search and resume customization.
- Support client/project proposal workflows.
- Support software building with Codex.
- Support automations through n8n.
- Keep the system safe through approvals and logs.

## Primary features

### Chat
User can type messages to Nami.

### Voice
User can speak to Nami using push-to-talk first, wake word later.

### Memory
Nami stores and retrieves useful context.

### Research
Nami searches, reads, summarizes, and creates action plans.

### Utilities
Nami checks weather, time, current information, and similar factual utilities.

### Automation
Nami triggers n8n workflows.

### Email/calendar
Nami drafts emails, summarizes email, schedules meetings with approval.

### Resume/job assistant
Nami customizes resume, creates cover letters, tracks applications, and prepares job workflows.

### Browser/screen
Nami uses browser automation and later screen control with safety.

### Codex builder
Nami creates Codex-ready tasks and helps manage software builds.

## MVP

Nami V1 includes dashboard, chat, settings, logs, approvals, tasks/projects placeholders, basic AI integration, and n8n test.

## Success metrics

- User can run app locally.
- User can chat with Nami.
- Approval system exists.
- Logs are created.
- n8n test works.
- No secrets committed.
- Codebase is modular.
