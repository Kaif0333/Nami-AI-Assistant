# 64 — Internal Privacy Policy

## Principles

- User controls memory.
- User can delete memory.
- Screen/mic status must be visible.
- No secret recording.
- No hidden monitoring.
- Do not upload private files without approval.
- Do not share data externally without approval.

## Sensitive data

Sensitive data includes:
- API keys
- Passwords
- Email contents
- Resume/personal data
- Client info
- Financial details
- Private files

## Retention

V1:
- Store only what is needed.
- Allow manual deletion.

Later:
- Add retention settings.
