# 39 — Document Generation

## Goal

Nami can create professional documents.

## Document types

- Resume
- Cover letter
- Project report
- DPR
- Proposal
- Invoice
- PPT outline
- PDF report
- Excel tracker
- Meeting notes
- Client requirement document
- Technical documentation

## Process

1. Understand purpose
2. Gather inputs
3. Draft content
4. Format
5. Export
6. Save/log

## Safety

- Do not include private data unless provided/approved.
- Ask before sending/sharing documents.
