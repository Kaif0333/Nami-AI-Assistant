# 92 — Local Setup Windows

## Required

- VS Code
- Git
- Node.js LTS
- Python
- Docker Desktop
- Codex extension
- Optional WSL2
- Optional Wispr Flow

## Clone repo

```bash
git clone https://github.com/Kaif0333/Nami-AI-Assistant.git
cd Nami-AI-Assistant
code .
```

## Common issues

### PowerShell script blocked

Run PowerShell as admin if needed:

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### Port in use

Find and kill process or change port.

### Node version

Use Node LTS.

### Docker not running

Start Docker Desktop.

### Git auth

Use GitHub login/token.
