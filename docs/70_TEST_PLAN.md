# 70 — Test Plan

## Goal

Every critical module must be testable.

## Test categories

- Unit tests
- Integration tests
- UI tests
- End-to-end tests
- Manual tests
- Security tests
- Voice tests
- Automation tests
- Screen/control tests

## Minimum before phase completion

- Build passes
- Lint passes
- Relevant tests pass
- No secrets committed
- Approval policy preserved
- Changelog updated
