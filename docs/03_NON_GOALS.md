# 03 — Non-Goals

Nami must not attempt to be:

- A conscious AI
- A perfect movie-level JARVIS
- A hidden surveillance tool
- A tool for bypassing CAPTCHA/paywalls/DRM
- An impersonation tool for job interviews
- A banking/payment automation tool without manual control
- A malware-like desktop controller
- A system that silently sends/deletes/submits data
- A one-prompt build-everything experiment

## Explicitly not allowed

- Secretly recording mic/screen
- Taking interviews on behalf of Kaif
- Sending emails without approval unless a safe rule is explicitly configured
- Submitting job applications without approval
- Accessing private accounts without user setup and consent
- Storing raw secrets in database logs
