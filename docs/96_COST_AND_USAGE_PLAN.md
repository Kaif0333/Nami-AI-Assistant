# 96 — Cost and Usage Plan

## Cost risks

- Voice sessions
- Vision/screen analysis
- Deep research
- Long videos
- Coding loops
- TTS
- Embeddings

## Cost control

- Use model routing.
- Use fast models for simple tasks.
- Use deep reasoning only when needed.
- Summarize transcripts before visual analysis.
- Track usage later.
- Let user set budget limits.

## Usage logs

Track:
- model
- task type
- tokens/cost if available
- timestamp
