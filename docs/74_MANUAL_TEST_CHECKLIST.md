# 74 — Manual Test Checklist

## Before every commit

- [ ] App starts
- [ ] No obvious console errors
- [ ] No secrets changed
- [ ] New feature tested
- [ ] Approval rules not bypassed
- [ ] Docs updated
- [ ] Changelog updated

## UI

- [ ] Sidebar works
- [ ] Pages load
- [ ] Buttons work
- [ ] Empty states exist
- [ ] Error states exist
- [ ] Loading states exist

## Safety

- [ ] Risky action creates approval
- [ ] Reject blocks action
- [ ] Approve executes action
- [ ] Logs are stored
